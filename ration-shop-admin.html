Google Sheets Integration Guide
  1. Click any Export CSV card above to download the data file.
  2. Open Google Sheets and create a new spreadsheet.
  3. Go to File → Import → Upload and select the downloaded CSV file.
  4. Select "Replace current sheet" and click Import data.
  5. Repeat for each data type (Shops, Items, Schedules, Announcements) in separate sheets.
  6. Use the Google Sheets API or Apps Script to push updates back to this system.
